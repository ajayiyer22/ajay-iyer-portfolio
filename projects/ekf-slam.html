Problem & goal

A moving robot must estimate where it is while identifying landmarks from noisy measurements. During an internship, I studied joint estimation in a MATLAB EKF-SLAM simulator and separately implemented encoder assisted navigation on embedded hardware.

Approach & implementation

  • EKF-SLAM. Adapted a credited MATLAB simulator to estimate robot pose and landmark positions with prediction and measurement updates and Jacobian based covariance propagation.
  • Data association. Matched range and bearing observations to landmarks using Mahalanobis gating, then examined how repeated observations changed map uncertainty.
  • Embedded navigation. Programmed ultrasonic obstacle avoidance and encoder feedback in Embedded C for a SPARK-V robot with an ATmega16 controller.

Implementation & results

Reobserving landmarks reduced estimated map uncertainty in simulation. The separate SPARK-V implementation demonstrated room traversal with obstacle avoidance.
