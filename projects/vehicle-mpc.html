Overview

A model predictive control study for vehicle trajectory tracking under steering, acceleration and speed constraints. A reference-scheduled prediction model is evaluated against a nonlinear vehicle simulation, including startup errors and external disturbances.

  1. Measure tracking error
  2. Schedule prediction model
  3. Build constrained QP
  4. Apply first command
  5. Simulate & repeat

Technical contributions

  • Prediction model. Formulated along-track, cross-track, heading and speed errors relative to a time-indexed reference. Scheduled the local prediction model using reference speed and curvature over a 20-step horizon.
  • Constrained control. Implemented a sparse quadratic program using OSQP with steering, acceleration, command-rate and speed bounds. The controller applies the first optimized input and replans every 100 ms of simulated time.
  • Validation. Evaluated variable-speed oval, figure-eight and disturbed lane-change scenarios using a nonlinear kinematic bicycle model. Measured tracking and recovery performance alongside independent checks of command and sampled-speed limits.

Results

All 1,520 optimization solves succeeded across three kinematic simulation scenarios. Position RMSE ranged from 0.289 to 0.396 m, including startup recovery; configured constraint checks passed.

Simulation setup

The experiments use a four-state kinematic vehicle with perfect state feedback and a known reference. Tire slip, measurement noise, and actuator lag are outside this model. These scenarios are separate from the earlier six-state reference-code study.
